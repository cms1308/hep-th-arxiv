# arXiv hep-th 데일리 브리핑

매 평일 arXiv `hep-th` 신규 제출 논문(cross-list 제외)의 제목·저자·카테고리·abstract와
한국어 abstract를 정리해 자동으로 커밋합니다.

**아카이브:** https://cms1308.github.io/hep-th-arxiv/

- `index.html` — 발행 목록 (manifest.json에서 자동 생성)
- `briefs/YYYY-MM-DD.html` — 각 날짜 브리핑
- `manifest.json` — 발행 메타데이터

출처: https://arxiv.org/list/hep-th/new · 한국어 abstract는 기계 번역입니다.

수집·번역·발행: 로컬 예약 실행 + GitHub Actions 워크플로 `hep-th 데일리 브리핑`.
매 평일 11:07~23:37 KST에 30분마다 확인하며, 발행한 날은 바로 종료합니다.
마지막 확인까지 미발행이면 알림을 남깁니다. 설정과 로그 확인 방법은 [RUNBOOK.md](RUNBOOK.md)를 참고하세요.
